# 递归解压GUI程序

这是一个基于PyQt5的图形用户界面程序，用于处理国网电力招标文件。它可以递归解压缩ZIP和RAR文件，整理采购文件包，处理技术规范书，并生成Excel汇总表。

## 功能特点

1. **图形用户界面**：使用PyQt5实现的直观界面
2. **递归解压**：自动解压ZIP和RAR文件，包括嵌套的压缩文件
3. **文件整理**：自动组织采购文件包和技术规范书
4. **Excel汇总**：生成技术规范书和工程量清单的Excel汇总表
5. **打开目标文件夹**：处理完成后，可以直接打开目标文件夹查看结果

## 系统要求

- Python 3.6+
- PyQt5
- openpyxl
- LibreOffice（用于DOC到DOCX转换）
- unar（用于RAR文件解压，可选）

## 安装步骤

1. 安装Python依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 安装系统依赖：
   - macOS: `brew install unar`
   - Ubuntu: `sudo apt-get install unar`
   - 安装LibreOffice: https://www.libreoffice.org/download/download-libreoffice/

## 使用方法

### 方法1：使用启动脚本（推荐）
```bash
./run_gui.sh
```

### 方法2：直接运行Python文件
```bash
python3 recursive_unzip_gui.py
```

## 使用说明

1. **选择源目录**：点击"选择源目录"按钮，选择包含招标文件的目录
2. **选择目标目录**：点击"选择目标目录"按钮，选择处理后文件的保存位置
3. **开始处理**：点击"开始处理"按钮，程序将自动处理文件
4. **查看进度**：在日志区域查看处理进度和详细信息
5. **打开目标文件夹**：处理完成后，"打开目标文件夹"按钮将变为可用状态，点击即可直接打开目标文件夹查看处理结果

## 新增功能

### 打开目标文件夹

处理完成后，程序会启用"打开目标文件夹"按钮，点击该按钮可以直接在文件管理器中打开目标目录，方便查看处理后的文件。

- 该按钮在处理完成前处于禁用状态
- 支持Windows、macOS和Linux系统
- 会自动检测操作系统并使用相应的命令打开文件夹

## 注意事项

1. 确保有足够的磁盘空间存储解压后的文件
2. 处理大量文件可能需要较长时间，请耐心等待
3. 如果处理中断，可以重新运行程序，它会跳过已处理的文件
4. 建议在处理前备份重要文件

## 故障排除

1. **PyQt5安装失败**：尝试使用 `pip install PyQt5` 手动安装
2. **RAR文件无法解压**：确保已安装unar工具
3. **DOC文件转换失败**：确保已安装LibreOffice并正确配置
4. **程序无法启动**：检查Python版本是否为3.6或更高版本
